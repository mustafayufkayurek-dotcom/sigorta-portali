# UI Referans Ekranları

Bu klasör, Meridyen **onaylı referans PNG** dosyalarının tek kaynağıdır.

## Ne referans değildir

- Mevcut uygulama ekranı
- Eski screenshot’lar
- Component yerleşimi veya kod

Bunlar UI için referans sayılmaz.

## EPIC-05 (Acil Yardım dosya detayı) — onaylı referans

**Dosya:** `acil-yardim-dosya-detay-referans.png`

Bu PNG, EPIC-05 dosya detayı için **onaylı tek tasarım kaynağıdır**.

- Mevcut uygulama ekranı referans değildir.
- Eski canlı kabul / capture screenshot’ları referans değildir.
- Bölüm bölüm uygulama yalnızca bu PNG’ye göre yapılır.

## Hasar Operasyon Planlayıcısı — güncel onaylı referans

**Dosya:** `HASAR_OPERASYON_PLANLAYICISI_FINAL_REFERANS.png`

Bu PNG, Hasar dosyası ana ekranı + 8 adımlı Operasyon Planlayıcısı için **güncel bağlayıcı tasarım kaynağıdır**.

- Standart: `docs/project-governance/canli-kabul/HASAR_OPERASYON_PLANLAYICISI_UX_STANDARDI_20260719.md`
- Lokal rota: `/dev/hasar-operasyon-planlayicisi`
- Eski 6 perdeli lokal standart silinmedi; superseded olarak işaretlendi.

## Geliştirme kuralı

Referans PNG bu klasörde yoksa UI geliştirme durur. Varsa yalnızca bu PNG’ye uyulur; yorum veya yeniden tasarım yapılmaz.
